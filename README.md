# EcoHealth-Predict
EcoHealth Predict est une application web fullstack conçue pour l'acquisition en temps réel de données télémétriques (santé/énergie), leur stockage sécurisé, leur analyse visuelle et la prédiction de tendances via Machine Learning. Il combine développement bas-niveau (C), ingénierie logicielle (Python/SQL), science des données et DevOps (Docker)
